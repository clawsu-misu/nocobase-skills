# 术语词典 — 《NocoBase 官方文档（中文版）》

> 按出现频率与理解难度排序。首次出现的英文原名一并给出，便于与官方英文文档对照。
> 术语的「作者用法」与常识用法的差异已在定义中标注。

| 英文原名 | 中文 | 定义 |
|---|---|---|
| Collection | 数据表 | 统一描述「数据存哪里 / 有哪些字段 / 如何被使用」的数据模型，是 NocoBase 对一类业务数据的完整描述，而非单纯的数据库表名。 |
| Field | 字段 | Collection 中描述数据的一项业务属性，含「保存什么数据 / 页面怎么用 / 如何参与业务能力」三层含义。 |
| Block | 区块 | 页面/对话框/抽屉中数据与内容的载体，是数据在界面上的投影单元。 |
| Action | 操作 | 触发一段指令的按钮，须与区块组合使用，可见性由数据表资源权限统一决定。 |
| Association field | 关系字段 | 保存表与表之间连接配置及定位关联记录的键。 |
| Through collection | 中间表 | 多对多关系中承载两份外键、保存两实体关联的表。 |
| Record unique key | 记录唯一标识 | 用于在区块中唯一定位一条记录的字段或字段组合；视图表与 SQL 表必须配置。 |
| Data scope | 数据范围 | 为数据区块或关系字段定义的默认筛选条件，始终生效；区块级只是前端过滤，服务端级才是安全边界。 |
| Linkage rule | 联动规则 | 「左变量 + 操作符 + 右值」三元组，条件满足即调整区块/字段/操作的展示与行为；多规则以最后一条为准。 |
| Event flow | 事件流 | 在页面/区块/按钮/字段的事件上编排自定义步骤的机制，可在系统内置流程的指定位置插入逻辑。 |
| RunJS | RunJS | 在界面设计器中在线编写并运行 JS 的轻量扩展方式，含 JS Block / Field / Column / Item / Action 五种载体。 |
| UI template | UI 模板 | 区块/字段/弹窗三类配置模板，分「引用（同步）」与「复制（独立）」两种模式。 |
| Trigger | 触发器 | 工作流的执行入口。创建工作流时选定，创建后不可修改类型。 |
| Node | 节点 | 工作流内执行特定操作的基本逻辑单元，节点间以上下游关系组成流程。 |
| Execution | 执行计划 / 执行记录 | 工作流触发后的具体执行对象，含状态与触发上下文，以及各节点的执行结果。 |
| Revision | 版本 / 修订 | 同一工作流的不同配置版本；切换启用即生效，历史执行不受未来修改影响。 |
| Pre-action / Post-action event | 操作前 / 操作后事件 | 分别在请求被处理前、以及用户操作成功后触发；前者可拦截，后者带用户信息且可局部绑定按钮。 |
| Collection event | 数据表事件 | 监听数据表增删改查事件的触发器，更靠近系统底层，无用户信息，可能连锁触发。 |
| ACL | 访问控制列表 | NocoBase 的权限控制体系，负责角色、资源、操作、字段与数据范围的授权。 |
| Union role | 联合角色 | 多角色权限按最大权限合并的策略，行与行满足其一即可、列与列字段相加。 |
| Variables & Secrets | 变量与密钥 | 集中配置和管理环境变量与密钥，用于敏感数据存储、配置重用、环境隔离。 |
| Release / Migration / Backup | 发布 / 迁移 / 备份 | 发布 = 可重复可验证可回退的交付机制；迁移 = 跨环境发布配置与结构；备份 = 运行态全量备份与容灾。三者不可互相替代。 |
| Multi-app / Multi-space / Multi-portal | 多应用 / 多空间 / 多工作区 | 分别是物理隔离、逻辑数据隔离、多入口三种扩展能力。 |
| Cluster mode | 集群模式 | 通过多实例/多核提升并发与高可用；需商业插件、Redis/RabbitMQ、共享存储与负载均衡。 |
| AI Employee | AI 员工 | 由人设（Role setting）和技能（Tool/Skill）组成、可在业务界面理解上下文并执行操作的智能体。 |
| Skill / Tool | 技能 / 工具 | 在 AI 员工语境下：技能是给 AI 的专业领域知识指南，工具定义 AI「能做什么」。注意与 NocoBase Skills（给外部 Agent 的领域知识包）区分。 |
| Knowledge Base | 知识库 | 组织文档、生成分段和向量索引，为 RAG 提供可维护的数据来源；分 Local / Readonly / External 三类。 |
| RAG | 检索增强生成 | 问题向量化召回 Top-K → 拼接进增强提示注入上下文 → LLM 生成。命中的是分段而非整篇文档。 |
| Segment | 分段 | 文档按分段参数拆成的可检索单元，含 Chunk size / Chunk overlap / Related questions。 |
| Quick Task | 快捷任务 | 在区块或页面上预设的常用 AI 任务（标题 / 背景 / 默认提问 / 工作上下文 / 技能 / 工具），一键触发。 |
| MCP | Model Context Protocol | 标准化协议；AI 员工可接入 MCP 服务使用其工具，NocoBase 也可对外提供 MCP 服务接口。 |
| env | 环境（CLI） | NocoBase CLI 记住的一套应用连接与运行信息，后续命令默认围绕 env 执行。 |

共 32 条。出处：`docs/docs/cn/` 各目录，逐条可在对应能力卡的 R 段回溯。
